# Mastering Modern DevOps (Second Edition) — Book Manuscript & Companion Repository

**Author:** Christian Chostak  
**Title:** *Mastering Modern DevOps: A Comprehensive Guide to Infrastructure, Automation, and Cloud-Native Technologies (Second Edition)*

---

## Repository Structure

- **`chapters/`**: Complete Second Edition Docs-as-Code manuscript split into 27 numbered Markdown chapters (`01-preface-and-front-matter.md` through `27-conclusion-and-future-outlook.md`), including 26 embedded Mermaid architecture diagrams and 4 brand-new Second Edition chapters:
  - **Chapter 19**: *Platform Engineering and Internal Developer Platforms (IDPs)* (Backstage, Crossplane, Kratix Promises, Golden Paths, Cognitive Load)
  - **Chapter 20**: *eBPF Cloud-Native Networking, Cilium, and Ambient Service Mesh* (Cilium CNI, Hubble, Tetragon, Istio Ambient Mode, Gateway API)
  - **Chapter 21**: *OpenTelemetry Collector Pipelines, Continuous Profiling, and AI-Augmented SRE* (OTLP, Grafana Beyla eBPF, Tail-Based Sampling, Pyroscope, Multi-Window SLO Burn Correlation)
  - **Chapter 22**: *Software Supply Chain Security with SLSA, Sigstore Cosign, and SBOM Attestations* (SLSA Build L3, Keyless OIDC Signing, CycloneDX SBOMs, Kyverno Admission Verification)
- **`snippets/`**: 16 self-contained, print-safe (`<= 55` columns) companion configurations and verification scripts across AWS CDK, Boto3, Ansible, GitHub Actions, Docker, Kubernetes, Prometheus, Argo CD, Crossplane, Cilium, OpenTelemetry, and Sigstore/Kyverno.
- **`references/references.md`**: Curated IEEE-style bibliography covering 29 foundational and cloud-native standards.
- **`build/`**: Compiled KDP and Kindle eBook publishing artifacts generated by `bundle_book.py`:
  - `build/book.md` — Complete unified manuscript
  - `build/book.html` — Standalone interactive HTML5 book with embedded SVG cover and 26 inline vector diagrams
  - `build/book.epub` — Reflowable Amazon Kindle EPUB3 package
  - `build/book_pdf.md` & `build/header.tex` — Print-ready KDP 6x9 Trade Paperback source
  - `build/images/` — Vector SVG cover and 26 rendered architecture diagrams
  - `build/kdp_publishing_manifest.json` — Amazon KDP print and eBook publishing manifest
- **`01-cdk/` through `12-serverless/`**: Hands-on lab directories accompanying Chapters 1–11.
